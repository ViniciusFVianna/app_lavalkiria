## 📌 Sobre o Projeto

Este projeto foi desenvolvido como parte da disciplina de **Engenharia de Usabilidade** do curso de **Engenharia de Software**. O objetivo principal foi aplicar conceitos de IHC (Interação Humano-Computador), design centrado no usuário e avaliações heurísticas para criar uma interface eficiente para o contexto da **La Valkiria**.

A motivação partiu da necessidade de explorar como a usabilidade pode impactar a retenção de usuários e a facilidade de navegação em aplicativos de serviços/vendas.

## ✨ Funcionalidades

- [x] Interface baseada em protótipo de alta fidelidade.
- [x] Navegação intuitiva seguindo as heurísticas de Nielsen.
- [ ] Integração com backend para processamento de dados.
- [ ] Implementação de testes de usabilidade automatizados.
